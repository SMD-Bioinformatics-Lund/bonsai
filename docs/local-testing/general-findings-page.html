What passed

Expanded baseline
  • Table reading and exportPagination, selection across pages, name ordering, column visibility, filtered CSV and Excel export, and clearing advanced filters passed. Select all and basket display handled 125 records.
  • Group and record lifecycleGroup changes persisted. Deleting a populated group retained all 125 records, but a later preservation check found loss of unrelated memberships; that failure is listed above. Cancelling bulk deletion retained everything; confirming it removed exactly the 42 selected disposable records. Single-record deletion removed only its target.
  • Metadata navigationMetadata routes opened for all 80 original records in the baseline and all 125 records after the fixes. Interleaved fields and generic table headings and cells also passed the targeted retests.
  • Permissions and authenticationAfter the fixes, the owner and invited account could open the private group; an uninvited account could neither see nor directly open it. Keyboard login, incorrect-password feedback and navigation after logout passed. Expired-session handling was checked in the initial pass.
  • Comments and state changesComments preserved literal HTML as text, Unicode and attribution. Administrator removal retained a hidden audit record. Bulk status changes required a follow-up action on failure, persisted after reload, and cleared failure fields after a passed state.

Scope, evidence and limits

This is a development test instance using synthetic data and local Chromium/Selenium. It is preparation for a human release test, with no release certification implied.

  • Further testing and fixes cover general application behavior and read-only stored summaries. Analysis execution, clustering and curation writes remain excluded; the original evidence is preserved.
  • Real JASEN data, scientific correctness, LDAP/SSO, other browser engines, production-scale load and production deployment remain untested.
  • Phone-size overview checks found overflow. The separate findings page is checked at 320 px, 390 px and desktop widths.
  • Temporary destructive workflows used disposable records. A database snapshot and the original evidence were saved before expansion.
  • Fixes are prepared on a separate local branch, with focused regression checks and browser retests. No Git branches are pushed.
